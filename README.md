# push-football-game
A soccer game without the ball, made for a game jam where the theme was
"Genre X without Y". Five attackers run at your goal, and your only
tool is your body: push them away until the time runs out.

**Play it here:** https://imenelardjane.github.io/push-football-game/

## How to play
- Move your goalkeeper with the **arrow keys**.
- Touch an attacker to knock them back.
- Attackers that reach your goal line score a goal.
- Survive until the timer ends to win. Let in 3 goals and you lose.

## Features
- Menu, game over screen and Play again button
- Attackers get faster as the match goes on
- Collision, friction and wall bouncing written from scratch

## Built with
- JavaScript and [p5.js](https://p5js.org/)

## Run it locally
1. Download or clone this repository.
2. Open the folder in VS Code and run `index.html` with the Live Server extension.
